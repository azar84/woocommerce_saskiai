API Parameter Guide

Orders Parameters

  • id - Get a specific order by ID (e.g., id: 123)
  • search - Search by customer name, email, or order number
  • status - Order status (pending, processing, completed, etc.)
  • per_page - Number of results (1-100, default: 10)
  • page - Page number for pagination
  • orderby - Sort by date, id, include, title, slug
  • order - Sort direction (asc, desc)

Products Parameters

  • id - Get a specific product by ID (e.g., id: 123)
  • search - Search products by name or description
  • category - Filter by category ID or slug
  • tag - Filter by tag ID or slug
  • sku - Filter by SKU
  • status - Product status (publish, draft, private)
  • type - Product type (simple, grouped, external, variable)
  • featured - Featured products (true/false)
  • on_sale - Products on sale (true/false)
  • min_price - Minimum price filter
  • max_price - Maximum price filter
  • stock_status - Stock status (instock, outofstock, onbackorder)
  • average_rating - Minimum average rating (1-5)
  • per_page - Number of results (1-100, default: 10)
  • page - Page number for pagination
  • orderby - Sort by (date, id, menu_order, popularity, rating, title, price)
  • order - Sort direction (asc, desc)

Customers Parameters

  • id - Get a specific customer by ID (e.g., id: 123)
  • search - Search by name, email, or username
  • email - Filter by specific email address
  • role - Filter by user role
  • orderby - Sort by id, include, name, registered_date

Settings Parameters

  • No search parameters - Returns all WooCommerce settings
  • Settings are read-only in this interface
